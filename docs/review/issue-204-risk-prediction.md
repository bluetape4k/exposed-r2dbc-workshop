# Issue #204 위험 예측과 재실행 계약

이 문서는 `09-spring/06-exposed-spring-boot-r2dbc-repository` 구현 전에 승인된
설계와 실행 계획에서 예측한 위험을 조기 신호, 완화책, rollback 및 재실행

## 재검증 중지 조건

- provider transaction/lifecycle 의미가 승인 설계와 달라지면 service API를 늘리지 않고 T1–T5 gate로 돌아간다.
- P0 또는 P1 review finding, fresh targeted test 실패, workflow registration 근거 부재가 남아 있으면 T8 이후로 진행하지 않는다.
- 오류 로그에 SQL, R2DBC URL, credential이 포함되거나 pool leak/timeout이 재현되면 해당 slice를 실패로 유지하고 원인과 raw evidence를 남긴다.
